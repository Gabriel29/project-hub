# Branding assets

`client/public/brand/projecthub-logo.svg` is the neutral ProjectHub wordmark.
`projecthub-icon.svg` provides the matching browser icon. Both use a simple hub symbol.

`client/public/brand/workspace-placeholder.svg` is a decorative abstract workspace
illustration used on the login page. It contains no customer photos or company
artwork. These assets are local SVG files and require no external image service.
Replace them and the `brand.*` translations when customizing the portal.
